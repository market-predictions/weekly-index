# Index Report Compactness Rules

## Purpose

The Weekly Indices Review should become more research-aware without becoming crowded.

Research depth belongs in artifacts. The report should only show the highest-signal implications.

## Hard client-facing rules

- Max 5 bullets in Executive Summary.
- Max 3 `What changed` bullets.
- Max 3 macro / regime implications.
- Max 2 central-bank or policy references.
- Max 1 risk-watch sentence per compact regime block.
- No source dumps.
- No raw artifact labels.
- No process-language such as `runtime`, `artifact`, `board_capacity`, `near_miss`, `ruled_out`, `state-led`, or `check-only` unless explicitly placed in a technical appendix.
- No defensive / inverse candidate inside the long-side opportunity board.
- No duplicated Alternative Duel or Short Radar tables.

## Client-facing translations for artifact terms

| Artifact term | Client-facing wording |
|---|---|
| board_capacity | Not added to the action list this week |
| near_miss | Close to the board, but not yet fundable |
| ruled_out | Not promoted this week |
| weak_relative_strength | Weak relative strength |
| fragile_macro_alignment | Macro timing not strong enough |
| insufficient_immediate_priority | Not urgent enough for capital this week |
| held_but_not_board_named | Existing exposure, not a new capital priority |

## Transfer rule

A section may only grow if it changes a decision.

Examples of allowed transfer:

- regime change that alters Add / Hold / Reduce / Hedge status
- breadth signal that affects IWM, EEM or region funding
- USD or real-rate signal that affects EM, small caps or inverse readiness
- central-bank signal that changes duration or equity risk posture

Examples of disallowed transfer:

- generic macro commentary
- long central-bank summaries
- broad source summaries
- repeating the same regime label across multiple sections

## Validation intent

A compactness validator should warn on process terms and hard-fail on inverse/long-board mixing or missing required triggers, but should not block the report merely because a concise macro statement is reused once.
