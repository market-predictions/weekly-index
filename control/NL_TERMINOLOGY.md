# Weekly Index Review — Nederlandse Terminologie

## Doel

Dit bestand is de terminologiebron voor de Nederlandse Weekly Index Review.

De Nederlandse versie moet professioneel, helder en financieel natuurlijk Nederlands gebruiken. Vermijd letterlijke machinevertalingen en behoud de senior/institutionele toon van de Engelse versie.

---

## Stijlprincipes

1. Schrijf zakelijk, compact en besluitgericht.
2. Gebruik natuurlijk Nederlands, geen steenkolenengels.
3. Houd financiële termen consistent over alle rapporten.
4. Vertaal niet elk Engels woord letterlijk als een Nederlandse marktterm beter leest.
5. Laat tickers, indexnamen en ETF-symbolen ongewijzigd.
6. Gebruik Nederlandse datums, weekdagen en maandnamen.
7. Vermijd interne workflowtaal in client-facing tekst.
8. Gebruik `u` niet; schrijf neutraal/institutioneel.

## Verboden of te vermijden termen

| Vermijd | Gebruik liever |
|---|---|
| weerbaarheidsbouwstenen | defensieve bouwstenen |
| gefinancierde wissel | gefinancierde rotatie / positieaanpassing |
| kapitaal re-underwriting | kapitaalherbeoordeling |
| aandelencurve | vermogenscurve |
| prijsstelling basis | prijsbasis |
| live repo state | huidige rapportstatus / niet client-facing gebruiken |
| artifact rebuild | herbouw van rapportonderdelen / niet client-facing gebruiken |
| board_capacity | Niet tonen; vertaal naar client-facing reden. |
| near_miss | Niet tonen; vertaal naar `sterke kandidaat, nog niet gefinancierd`. |
| ruled_out | Niet tonen; vertaal naar `lagere prioriteit deze run`. |

## Authority rule

Bij twijfel:
1. behoud cijfers en tickers exact,
2. behoud de investeringsbeslissing exact,
3. kies natuurlijk Nederlands boven letterlijke vertaling,
4. houd de tekst compact en professioneel.
